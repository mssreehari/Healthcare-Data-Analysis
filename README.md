# Healthcare Data Analysis

## Overview

This project analyzes healthcare data from customer profiles, medical examinations, and hospitalization details using Microsoft Excel.

## Data Analysis Performed

- **Cancer History vs Smoking:** Analyzed the distribution of cancer history among smokers and non-smokers using a PivotTable and Pie/Donut Chart.
- **Transplant History:** Compared total major surgeries and average HbA1C between patients with and without transplant history.
- **Weight & Diabetes vs Charges:** Compared average healthcare charges across different Weight Status and Diabetes Status categories using a PivotTable and Column Chart.
- **Hospital Tier & State:** Compared average healthcare charges for different hospital tiers across states using a PivotTable and Bar/Column Chart.
- **Age vs BMI:** Used a Scatter Plot to explore the relationship between age and BMI.
- **Age vs HbA1C:** Used a Scatter Plot to explore the relationship between age and HbA1C.
- **Age vs Charges:** Used a Scatter Plot to explore the relationship between age and healthcare charges.

## Dashboard

An interactive Excel dashboard was created to bring the visualizations together. It includes slicers for:

- **Weight Status**
- **Diabetes Status**

These slicers allow the charts to be filtered interactively.

## Tools Used

**Microsoft Excel · PivotTables · PivotCharts · VLOOKUP · Pie/Donut Charts · Column/Bar Charts · Scatter Plots · Slicers**

## Workflow

`Data Cleaning → Data Transformation → Healthcare Master Table → Analysis → Visualization → Interactive Dashboard`
